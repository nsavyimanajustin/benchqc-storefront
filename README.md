# BenchQC Storefront Engine ⚡
> Turn-Key Verified Laptop Commerce & Hardware Quality Certification Platform

**BenchQC Storefront Engine** is an open-source, white-label e-commerce and hardware inspection portal built for refurbished/second-hand laptop retailers and tech labs. It pairs an e-commerce storefront with an embedded 5-dimension BenchQC hardware audit certificate (battery wear, display integrity, keyboard matrix, NVMe SMART health, and thermal load stability).

---

## 🌟 Key Features

### 1. High-Trust Certified Laptop Catalog
- **Dual Currency Architecture**: Native real-time toggle between Algerian Dinar (`DZD`) and US Dollar (`USD`) with configurable exchange rates.
- **BenchQC Quality Seals**: Instant visual badges for `Grade A+`, `Grade A`, and `Grade B` units with battery wear percentages and cycle counts.
- **Intended Use Filters**: Multi-tag filtering for Software Dev, Architecture/CAD, Gaming, Video Editing, and Student/Budget.
- **WhatsApp Direct Inquiries**: One-click WhatsApp button generating pre-formatted bilingual purchase requests with exact laptop ID, serial number, and quoted price.

### 2. Virtual Bench Inspection & Inspection Hold
- **Multi-Angle Gallery**: High-resolution image lightbox inspecting top lid, open keyboard/trackpad, display panel, side I/O ports, and bottom ventilation.
- **Detailed Spec Matrix**: CPU cores/clocks, RAM speed/type, GPU dedicated VRAM, NVMe TBW, and weight.
- **24-Hour Inspection Reservation**: Allows prospective buyers to reserve a unit for physical bench inspection without upfront card payment (`BQC-RES-XXXX`).
- **Official Verification Modal**: Printable verified certificate with cryptographic audit ID, QR code hash, and inspector credentials.

### 3. Retailer Intake & Inventory Studio (`Admin Portal`)
- **JSON Audit Auto-Ingestion**: Drag-and-drop or paste `benchqc_audit.json` generated by the **BenchQC Stress Engine** to instantly auto-populate hardware specs, battery metrics, thermal peak temperatures, and quality scores.
- **Quick-Fill Spec Templates**: 1-click presets for popular enterprise laptops (ThinkPad T14/L14, Dell XPS/Latitude, HP EliteBook 840, Apple MacBook Pro/Air, Lenovo Legion).
- **Inventory Lifecycle Management**: Toggle live inventory statuses between `Available`, `Reserved`, and `Sold`.

### 4. White-Label Customization Engine
- **Live Visual Customizer**: Tailor shop name, phone, WhatsApp number, Wilaya/city address, Google Maps embed, and working hours in real-time.
- **Dynamic Palette Switcher**: 5 curated accent themes (Tech Emerald, Cyber Cyan, Royal Blue, Amber Gold, Crimson Red) applied via CSS variables.
- **Instant Deploy / Config Portability**: 1-click JSON export/import of the entire store profile (`store_profile_<slug>.json`), allowing new partner retail shops to launch in under 5 minutes.

## 🏗️ Technology Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/) with custom CSS custom properties
- **Icons**: [Lucide React](https://lucide.dev/)
- **State & Storage**: React Context + `localStorage` local-first persistence (100% zero-backend required for standalone operation)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18+ or v20+
- `npm` or `pnpm`

### Installation
```bash
# Clone the repository
git clone https://github.com/nsavyimanajustin/benchqc-storefront.git
cd benchqc-storefront

# Install dependencies
npm install
```

### Development
```bash
# Run local development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🔗 Hardware Stress Engine Integration

The storefront consumes diagnostic JSON reports emitted by the **BenchQC Stress Engine**.
When running the stress test on a laptop:
```bash
benchqc-stress --output benchqc_audit.json
```
Upload or paste `benchqc_audit.json` in the **Retailer Studio** to automatically certify and publish the unit to your storefront. See [docs/AUDIT_SPEC.md](docs/AUDIT_SPEC.md) for the JSON schema.
